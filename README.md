# ThreadNote (지식스레드) 🧵📖

> **"지루하고 어려운 문서를 스레드(Threads) 특유의 신변잡기 일상 썰로 읽다"**

사용자가 올린 문서(학술 자료, 업무 기획서, 독서 메모, PDF 등)의 지식을 분석하여 인스타그램 스레드 특유의 유저 말투, 일상 속 넋두리, 에세이, 팩폭 썰로 재해석하여 인터랙티브 피드로 보여주는 앱입니다.

---

## ✨ 핵심 기능

1. **5가지 다채로운 스레드 화자(페르소나)**:
   - 💼 **스타트업 3년차 김대리**: "오늘 회의실에서 오열할 뻔한 썰... 결국 이게 문제였음" (직장인 애환 + 실무 팁)
   - 🌙 **새벽 2시 에세이스트**: "비 내리는 밤, 문득 창밖을 보다 떠오른 생각..." (잔잔한 일상 + 인문/철학)
   - ⚡ **극T 팩폭 엔지니어**: "감정 빼고 팩트와 숫자로만 3줄 요약함." (냉철한 논리 + 팩트 폭격)
   - 🔥 **스레드 1타 꿀팁러**: "이거 올릴까 말까 100번 고민함. 99%가 평생 속는 충격 진실 🧵👇" (후킹 + 스레드 타래)
   - 🐱 **골목길 냥집사의 통찰**: "오늘 우리 집 고양이 츄르 먹는 거 보다가 깨달은 인생 법칙" (사소한 일상 + 깊은 통찰)
   - 🎨 **커스텀 페르소나**: 원하는 말투(사투리, 사극톤, MZ 은어 등) 직접 입력 가능

2. **완벽한 Threads UI/UX**:
   - 1/3 시작 썰 -> 2/3 지식 연결 -> 3/3 실천 팁으로 이어지는 **스레드 타래 연결선** 시각화
   - **💡 원본 지식 엿보기 (Source Knowledge)**: 일상 썰 카드 뒷면에서 실제 학술 원문 인용구 및 메커니즘 확인
   - **💬 실시간 스레드 댓글 반응**: "ㄹㅇ 공감 ㅠㅠ", "이거보고 이직함" 등 가상 반응 및 직접 댓글 참여
   - **스레드 복사**: 인스타그램 스레드나 X에 바로 붙여넣기할 수 있는 완벽한 텍스트 포맷 복사
   - **좋아요 / 리포스트 / 북마크 보관함** 지원
   - **다크 모드 / 라이트 모드** 원클릭 전환

3. **초경량 제로 의존성 (Zero-Dependency)**:
   - Node.js나 npm, pip 설치 필요 없이 **Python 3 기본 내장 모듈만으로 즉시 구동**
   - 오프라인 스마트 텍스트 추출 & 템플릿 변환 엔진 기본 탑재
   - (선택 사항) Google Gemini API Key 입력 시 최신 AI 실시간 변환 가능

## 📁 프로젝트 구성

```text
threadnote/
├── app.py              # 로컬 웹 서버 및 페르소나 지식 변환 엔진
├── run.sh              # 원클릭 실행 스크립트
├── static/
│   ├── index.html      # Threads 스타일 단일 페이지 웹 UI
│   ├── style.css       # 메타 스레드 감성 다크/라이트 테마 CSS
│   └── app.js          # 인터랙티브 피드, PDF 추출, 댓글, 클립보드 복사 로직
├── samples/            # 1클릭 즉시 테스트용 샘플 지식 문서
│   ├── cognitive_bias.md # 확증 편향과 닻 내림 효과 (심리학)
│   ├── clean_code.md     # 단일 책임 원칙과 기술 부채 (소프트웨어)
│   └── dopamine_habit.md # 도파민 보상 회로와 스마트폰 중독 (뇌과학)
├── test_app.py         # 페르소나 엔진 단위 테스트
└── test_server.py      # HTTP 엔드포인트 핸들러 테스트
```
